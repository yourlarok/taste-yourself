# 尺码差异分析技术路线

## 目标与边界

尺码模块帮助用户理解“同一件衣服的不同尺码，穿着余量有什么差别”，不回答“应该买哪个”。

输出必须满足：

- 按商家原始尺码顺序展示，不建立排行榜。
- 不提供分数、星级、胜率、推荐尺码或默认选择。
- 数据不足时指出缺失项，不用身高体重猜出伪精确围度。
- 用“低于 / 位于 / 高于参考区间”等观察性语言，最终判断留给用户。

## 第一阶段：可解释规则

输入由三部分组成：

1. 用户尺寸画像：胸、腰、臀等围度，以及用户主动选择的穿着感受参照。
2. 商品数据：每个 SKU 的真实成衣围度、品类、弹性和版型。
3. 参考区间：不同品类与穿着感受下的常见穿着余量范围。

核心计算：

`穿着余量 = 成衣围度 - 人体围度`

API 对每个尺码分别返回人体尺寸、成衣尺寸、穿着余量、参考区间与区间关系。它不计算跨尺码综合得分，也不选择所谓最佳尺码。

## 第二阶段：验证参考区间

实际保留、换码、退货和具体部位感受用于检查参考区间是否合理，而不是训练一个替用户下决定的黑盒模型。分析时保留品牌、品类、面料弹性与版型分层，持续检查不同人群上的误差与偏差。

用户主动填写“偏贴身 / 符合预期 / 偏宽松”等穿后反馈，比“是否采纳系统结论”更符合产品定位。

## 第三阶段：相机与语音引导测量

不做开屏问卷。用户首次打开尺码差异且缺少可用画像时，界面解释用途并询问是否开始扫描。相机配合语音、人体轮廓和震动逐步引导站位、正面、侧面与缓慢转身；画面合格后自动取帧并由后台处理。

测量链路包括：

1. 手机端检查完整入镜、模糊、曝光、遮挡、姿态和运动速度。
2. 后台进行人体分割、相机尺度校准与参数化人体模型拟合。
3. 每项尺寸保存估计区间、质量状态、来源和模型版本。
4. 局部失败只补拍对应角度；无法获得绝对尺度时不输出厘米值。

问卷仅可作为无法扫描时的辅助恢复方案，不能成为必答主流程。用户也可以跳过扫描，继续静态或动态试穿。

## 3DGS 的位置

手机的多视角 3D/高斯重建可以帮助展示外观、检查覆盖角度或生成空间感更强的体验，但它不天然等于厘米级人体测量。只有经过相机标定、尺度约束并用软尺真值验证后，相关结果才能进入人体尺寸画像。

## 验证指标

- 自动测量相对软尺真值的 MAE、P95 误差和重复扫描一致性
- SKU 成衣尺寸数据完整率与异常率
- 用户展开尺码分析后能够理解差异的任务完成率
- 数据不足提示、跳过扫描和局部补拍的完成率
- 按品牌、品类、面料、人群切片后的误差和公平性
- 尺码相关换码/退货率仅作为长期业务观察指标，不反推为对单个用户的购买结论
