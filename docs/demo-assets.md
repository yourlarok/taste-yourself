# 内置服装目录素材

项目内置 19 件无品牌服装素材，均位于 `server/app/assets/garments/`。目录覆盖男女装、上衣、下装、连衣裙和外套，并在 `server/app/catalog.py` 中维护适用性别、体型、场景、材质和版型元数据，供魔镜 Agent 做可解释的筛选。

其中 16 件素材由内置 imagegen 工具生成。共同提示约束为：四宫格写实电商目录摄影、每格一件未穿着服装、正面、完整居中、纯白背景、柔和影棚光；不得出现人物、人体模特、衣架、品牌、文字或水印。原始四宫格通过 `scripts/crop_catalog_sheets.py` 裁切和压缩为 WebP。其余 3 件为项目早期生成的同风格素材。

这些图片是可实际选择并提交给试衣服务的预设服装，不代表第三方真实商品，也不携带商品尺码表。具体商品尺码仍以衣橱导入的尺码表和用户尺寸画像分析为准。
