# 演示服装素材

三张无品牌演示服装由内置 imagegen 工具生成，项目使用压缩后的透明 WebP：

- `server/app/assets/garments/knit-sand.webp`
- `server/app/assets/garments/denim-blue.webp`
- `server/app/assets/garments/coat-brown.webp`

生成模式：内置图像工具，`product-mockup`。共同提示约束为：单件未穿着服装、正面、完整居中、透明背景、写实电商目录摄影；不得出现人物、人体模特、衣架、品牌、文字或水印。三张素材的主体分别为米色细针织圆领上衣、深靛蓝牛仔夹克和暖棕色短款羊毛混纺外套。

这些图片只用于开发与内测输入，不代表真实商品，也不应与尺码数据或生成效果准确性绑定。
