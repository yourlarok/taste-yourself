# 微信开发者工具端到端测试

## 当前可测试范围

小程序只连接真实后端，不包含 Mock 数据层。未配置的 Provider 必须明确显示不可用，不能生成占位结果。

可测试：

- 加载 19 件原创预设服装，并按女装、男装、体型标签筛选
- 创建并持久化镜前体验会话
- 用 FASHN 真实 Provider 定格本人画面并触发静态试穿任务
- 展开来自后端的逐尺码差异
- 用 Bodygram 或兼容测量服务创建真实尺寸画像
- 录制最长 15 秒语音，经 Qwen ASR 转写后送入同一条魔镜会话
- 通过淘宝开放平台把商品链接加入私有衣橱
- 在 DevTools 编译并检查内嵌实时页面入口；DevTools 不用于证明摄像头 WebRTC 兼容
- Provider 不可用时给出明确状态，不影响其他功能

暂不可验收：真实换装质量、真实人体测量精度、模型处理视频流、正式微信登录与体验版发布；这些需要外部账号、GPU/供应商和平台权限。

## 1. 启动后端

在 PowerShell 中运行：

```powershell
cd C:\Users\Administrator\taste-yourself\server
python -m pip install -e ".[dev]"
..\scripts\start-dev.ps1
```

打开 `http://127.0.0.1:8000/docs`，确认 Swagger 页面可访问；`http://127.0.0.1:8000/health` 应返回 `{"status":"ok"}`。

## 2. 导入微信开发者工具

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择 `C:\Users\Administrator\taste-yourself`。
3. 当前 `project.config.json` 已配置项目 AppID；如用其他小程序账号测试，再替换为对应 AppID。
4. 打开“详情 → 本地设置”，仅在本地开发期间勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 点击“编译”。

正式体验版不能依赖这个本地开关；必须使用备案、有效 HTTPS 证书且已在小程序后台登记的请求域名。
`miniprogram/env.js` 的 `baseUrl` 必须是后端地址；发布体验版前必须使用已加入微信 request/uploadFile/downloadFile 合法域名的 HTTPS 地址。

## 3. 验收脚本

1. 首页是一面可对话的“猫猫魔镜”，可输入文字或录音，不是功能卡集合。
2. 询问海边穿搭时，Agent 返回真实服装 ID，并把 beach 场景带入实时试衣页。
3. 进入试衣间后可按女装/男装和体型标签筛选 19 件预设衣服，也可上传图片或粘贴淘宝链接。
4. 点击“定格试穿”，FASHN 返回真实生成结果；失败时明确提示，不显示预置图片。
5. 首次点击“查看尺码差异”，看到扫描用途说明；可选择“暂不扫描”验证数据不足状态。
6. 再次打开并选择“开始相机扫描”，真实画像完成后重新打开尺码抽屉，看到人体—成衣余量说明；没有分数或推荐。
7. 点击“实时试衣镜”。若 Decart 未配置，必须看到“不可用”，不能出现录像选择、排队状态、倒计时演示或静态画面冒充实时流。
8. 进入“我的”，确认所有能力的真实运行状态和今日用量可见；分别测试“清除尺寸画像”和“删除全部数据”。
9. 停止后端后重新进入，页面应明确提示连接失败，不应白屏或伪装生成成功。

画像状态会与服务端同步；请通过“我的 → 清除尺寸画像”重复测试首次扫描分支。

## 4. 自动化检查

```powershell
cd C:\Users\Administrator\taste-yourself
.\scripts\check.ps1
```

该脚本检查 Python、全部后端测试、小程序 JavaScript/JSON、WXML 基本结构和生产 Compose 配置。

## 5. 真机与体验版的外部条件

以下项目必须由小程序账号管理员或服务供应商提供，无法仅靠仓库代码生成：

- 正式小程序 AppID、管理员与体验成员名单
- 已备案的 HTTPS API 域名和有效证书
- 小程序后台的 request、uploadFile、downloadFile、socket 合法域名
- 隐私保护指引及摄像头、相册、人体尺寸数据用途声明
- 对应服务类目；实时音视频组件所需的主体、类目和权限
- 静态试穿、实时试穿和身体测量服务的账号、密钥、区域与数据处理条款

这些信息齐备后，关闭“不校验合法域名”，在真机上重新执行完整验收，再上传为体验版。
