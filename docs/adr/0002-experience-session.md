# ADR 0002：镜前体验会话是系统主链路

- 状态：已采纳
- 日期：2026-09-24

## 决策

以 `experience_session_id` 作为一次“进入镜前 → 选衣 → 静态试穿 → 查看尺码差异 → 可选 15 秒动态试穿”的关联主键。

产品核心是连续的线上试衣空间。静态试穿是默认体验；尺码模块只分析各尺码的客观差异，不排序、不打分、不替用户做购买决定；实时视频和 3DGS 是可选增强。身体扫描是可替换的数据入口，只在用户需要尺码分析且缺少可靠画像时触发。

## 原因

- 用户的目的不是分别使用三个工具，而是在一个空间里自然地看、比较和尝试。
- 静态试穿成本低且稳定，适合作为进入镜前后的默认状态。
- 尺码差异适合按需展开，避免结果页把体验变成导购结论。
- 实时模型可能失败或更换供应商，15 秒增强模式不应成为主流程依赖。
- 统一会话可以保存当前衣服、画面、画像版本与分析依据，并支持恢复最近一次体验。

## 约束

- 不向用户输出综合分、推荐尺码、购买结论或伪概率。
- 每次分析记录画像、商品尺寸、参考区间与算法版本。
- 相机采集与身体测量分离：手机负责引导和质量门控，后台负责重计算。
- 权限按需申请；拒绝身体扫描不影响普通试穿。
- 原始身体图像遵循最小化、限时保存和可删除原则。
