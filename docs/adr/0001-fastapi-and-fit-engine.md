# ADR 0001：FastAPI 与可解释尺码分析基线

- 状态：已采纳
- 日期：2026-09-24

## 决策

API 服务选用 Python 3.11 + FastAPI。第一版尺码能力使用可解释的“人体尺寸—成衣尺寸—穿着余量”规则，对每个尺码分别描述其与参考区间的关系。

系统不计算综合分，不输出推荐尺码、置信概率或购买结论。实时试穿通过 provider 边界接入第三方 WebRTC/API；模型密钥、权重和供应商协议不进入业务域，从而可替换供应商或迁移到自部署模型。

## 原因

- Python 方便后续接入人体参数模型、姿态估计和测量误差分析。
- 规则基线可解释、可审计，能明确暴露缺失数据与参考区间来源。
- 试穿负责视觉体验，尺码模块负责陈列差异；二者共享会话，但不互相冒充。
- 用户反馈用于验证和调整参考区间，而非训练一个替用户选择尺码的黑盒。

## 后续

1. 导入真实 SKU 成衣尺寸并建立品牌、品类和弹性配置。
2. 将分析输入、逐尺码结果与数据版本写入 `fit_analysis_logs`。
3. 用穿后反馈持续评估参考区间，并进行人群与品类切片检查。
4. 照片或视频测量只作为带误差范围的数据来源；未经软尺真值标定，不得作为唯一依据。
